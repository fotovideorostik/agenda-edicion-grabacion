Paso 2: En Repository access, selecciona solo el repositorio de tu agenda. En Permissions → Repository permissions, activa Contents: Read and Write.

Paso 3: Copia el token generado (`github_pat_...`), pégalo abajo junto a tu usuario y repositorio. Si schedule.json aún no existe, se inicializará automáticamente.
